## SHAP (SHapley Additive exPlanations)

SHAP is an Explainable AI (XAI) technique that interprets machine learning models by quantifying each feature's contribution to a prediction 
using Shapley values from game theory. It provides both **global** (overall feature importance) and **local** (individual prediction) explanations, 
making models more transparent, trustworthy, and easier to debug.
